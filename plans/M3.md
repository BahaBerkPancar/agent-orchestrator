# M3: Replay + approval UI + showcase

GOAL: Make every run reproducible and reviewable: replay a run from its event log without a model,
turn a failing run into a regression test, approve risky calls from a small local page, and finish
the README as a showcase with a recorded demo.

SCOPE: `src/agent_orchestrator/` (replay, web), `tests/`, `examples/`, README/DECISIONS/CHANGELOG.
Keep all M1/M2 guarantees and tests.

RULES: No paid APIs; Ollama on 127.0.0.1:11434 only (`qwen2.5:3b`; don't pull models) and only for
the one recorded demo run. Tests never need Ollama. Web page binds 127.0.0.1 only. Never read
`.env`. Tools never make real network side effects. Do not commit or push.

STEPS:
1. **Replay** `agent replay <run> [--home]`: rebuild a fresh run in a temp home from the original
   event log, feeding the recorded model outputs (a `ReplayModel`) and recorded approval decisions;
   tools re-execute in a fresh sandbox (same demo DB, same seeded workspace). Compare each new
   event to the original (type, tool name, args, ok, result hash); report the first divergence or
   "identical". Child (delegated) runs replay too. Non-deterministic fields (timestamps, ids) are
   excluded from the comparison, and the rule is documented.
2. **Replay to test** `agent replay <run> --to-test tests/regressions/test_<name>.py`: writes a
   self-contained pytest that replays the recorded outputs and asserts the final status/answer and
   the tool-call sequence (the failure-forensics idea). Generated tests must pass when written and
   be readable (no giant inline blobs: recorded outputs go to a JSON fixture next to the test).
3. **Approval page** `agent web` (FastAPI or stdlib, 127.0.0.1:8070): list runs with status;
   run detail = event timeline; pending approval shows tool, risk, args (escaped), with Approve /
   Reject / Edit-args (JSON validated against the tool schema) buttons that call the same engine
   path as the CLI (single source of truth, run lock respected). CSRF-safe form posts (token per
   session), no CDN, escaped everything, light/dark.
4. **Demo**: one recorded Ollama run of a multi-step task that needs an approval (e.g. the
   "thank the top customer" task), approved through the web page's code path, then `agent replay`
   → identical, and `--to-test` → a passing regression test committed under
   `tests/regressions/`. Put the transcript (`agent show`) in README.
5. **Tests**: replay identical for scripted runs (incl. approvals, edits, rejections, delegation,
   crash+resume), divergence detection when a tool result changes, generated test passes and fails
   when behaviour changes, web endpoints (list, detail, approve/reject/edit, CSRF rejection, schema
   validation of edited args, lock respected), escaping of hostile args.
6. Docs: README showcase (what/why, architecture sketch in text, guarantees, the M2 eval table,
   the demo transcript, limits), DECISIONS (replay comparison rule, web stack), CHANGELOG.

DONE WHEN: `uv run pytest && uv run ruff check .` pass offline; the demo run was recorded once
against local Ollama, replays identical, and its generated regression test passes.

ESTIMATE: 90–120 min.

REPORT: report contract (CHANGED / EVIDENCE / ESTIMATE vs ACTUAL / NOTES / VERDICT). Do not commit,
do not push.
