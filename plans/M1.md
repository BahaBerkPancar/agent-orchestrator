# M1: Core runtime

GOAL: A tested, offline agent runtime with durable checkpoints, governed tools, approval interrupts
and budgets, driven by a scripted fake model. See plans/ROADMAP.md.

SCOPE: `src/agent_orchestrator/` (keep the package name), `tests/`, `examples/`, `pyproject.toml`/
`uv.lock`, README/DECISIONS/CHANGELOG.

RULES: No network (Ollama arrives in M2), no LLM calls, never read `.env`, don't touch other repos.

STEPS:
1. **Decide LangGraph vs own state machine** after a short spike (install `langgraph` +
   `langgraph-checkpoint-sqlite` offline from the uv cache if available; if not installable offline,
   build the own state machine). Criteria: durable resume after process kill, interrupts for
   approval with edit/reject, deterministic replay from an event log, small dependency surface.
   Record the decision and the spike result in DECISIONS.
2. **State & events**: a run has id, goal, status (`running`, `waiting_approval`, `done`, `failed`,
   `budget_exceeded`, `cancelled`), messages, scratchpad, step counter, budget usage. Every
   transition appends an event (`model_call`, `tool_requested`, `approval_requested`,
   `approval_decided`, `tool_result`, `error`, `budget_hit`, `finished`) to an append-only SQLite
   log with a monotonic sequence; the checkpoint is derived state that can be rebuilt from events.
3. **Model interface**: `Model.next(state) -> Action` where Action is `ToolCall(name, args)`,
   `Delegate(...)` (stub for M2), `Finish(answer)`, or `Fail(reason)`. `ScriptedModel` replays a list
   of actions (and can inject malformed actions to test validation).
4. **Tools**: registry with name, description, JSON-schema args (validated with `jsonschema` or
   pydantic), `risk` (`safe`, `review`, `forbidden`), and an execute function. Built-ins: `fs_read`,
   `fs_write`, `fs_list` confined to a per-run workspace (path traversal and symlink escapes
   rejected), `calc` (safe arithmetic parser — no `eval`), `sql_query` (read-only SQLite on
   `examples/data/shop.db`, SELECT only), `send_email` (risk `review`; appends to
   `workspace/outbox.jsonl`, never sends). `fs_write` outside `workspace/drafts/` is `review`.
5. **Approval**: a `review` tool call pauses the run (`waiting_approval`) and persists; `agent approve
   <run> --decision approve|reject|edit --args '{...}'` resumes; edits are re-validated; rejections
   are fed back to the model as an observation. Policy file `policy.toml` can auto-approve by tool +
   args pattern.
6. **Budgets**: max steps, max tool calls, max model tokens (counted by the model adapter; fake
   counts words), max wall time; exceeding any → `budget_exceeded` with the reason, no further tool
   calls.
7. **Durability**: kill-and-resume test: run in a subprocess, kill it mid-run (after a checkpoint),
   `agent resume` continues without repeating completed tool calls (idempotency key per tool call;
   tools with side effects check it).
8. **CLI**: `agent run --goal ... --script script.json`, `agent resume`, `agent approve`, `agent show
   <run>` (timeline of events), `agent runs`. Exit codes documented.
9. **Tests**: state machine transitions; each tool incl. traversal/symlink escapes and SQL write
   attempts; calc rejects code; approval flows (approve, edit, reject, auto-approve policy); budgets;
   kill-and-resume without duplicate side effects; event log rebuilds the checkpoint exactly;
   malformed model actions handled.
10. Docs: README (what/why, a scripted demo run transcript), DECISIONS, CHANGELOG.

DONE WHEN:
- `uv run pytest && uv run ruff check .` pass offline.
- `examples/demo.sh` runs a scripted multi-step task that pauses for an email approval, is approved
  from the CLI, and finishes; `agent show` prints the timeline.

ESTIMATE: 120–150 min.

REPORT: end with the report contract (CHANGED / EVIDENCE / ESTIMATE vs ACTUAL / NOTES / VERDICT).
Do not commit, do not push.
